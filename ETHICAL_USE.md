# Authorized use / 授权使用

Use ArmorBreak with files, systems, or environments you own or have
explicit permission to assess. Keep artifacts and credentials within the
approved scope, and review findings before acting on them.

The Core determines permissions from its policy, scope and approval record.
Model responses and browser session tokens cannot grant privileged access.
The local Workbench exposes read-only operations. The project declines
requests for unauthorized access, credential theft, persistence and
destructive automation. These are project and product policies. The
[MIT License](LICENSE) contains the software licensing terms.

请仅在已授权的范围内使用，保护证据和凭据，对分析结论进行复核。浏览器
或模型的响应不具备特权授权能力。敏感缺陷按 [SECURITY.md](SECURITY.md) 报告。
