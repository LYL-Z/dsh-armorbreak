# Support / 支持

For installation, usage or compatibility problems, use the
[issue forms](https://github.com/LYL-Z/dsh-armorbreak/issues/new/choose).
Include the release or commit, OS and architecture, Node version, entry point
and a redacted example. The [distribution guide](docs/v24/distribution.md)
lists installation and verification steps.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). Use synthetic inputs
for public reports and remove credentials, real target data and personal paths.

安装或兼容问题请使用 Issue 模板，注明版本、操作系统、Node 版本和运行入口。
漏洞请走安全报告渠道。公开证据请先脱敏。
