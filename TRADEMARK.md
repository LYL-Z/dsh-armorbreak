# Project identity / 项目标识

Use **ArmorBreak** in English and **破甲** when referring to the project in
Chinese. The project shield is in [icon.svg](icon.svg). Use an explicit
fork or derivative label when distributing a modified build under your
own name, and describe compatibility with DeepSeek Harness accurately.

[LICENSE](LICENSE) gives the terms for the software. Project identity and
claims of endorsement are handled separately.
