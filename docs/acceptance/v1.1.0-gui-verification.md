
## 9. 真实桌面 GUI + 真实模型验证（2026-10-20）

使用 Windows UIA/截图驱动真实 Electron 窗口（Browser Control 扩展离线，但 UIA 即真实 GUI）：

- **真实模型 E2E**：新建会话 → 切换「破甲模式」→ 发送"调用 armorbreak_health"。模型真实调用工具并回复：41 capabilities / 8 domains / `isolation.state = 可用 (docker)`。截图 `docs/acceptance/screenshots/gui-model-e2e.png`。
- **状态卡视觉验证**：右侧 composer dock 卡片真实渲染并展开：41 项能力、5 个任务、隔离 `DaemonReady`、L2 显示"无授权目标"、L1 显示"docker 守护进程可用（未执行隔离自检）"、L3 拒绝；工作区绑定显示 `session-bound (recorded from tool activity)`。截图 `gui-status-card.png`。
- **工具中心探测**：点击"探测工具"后展示外部工具矩阵：Docker ✅、Python ✅；Semgrep/Trivy 在桌面进程 PATH 中未检测到（安装在 D:\dsh-tools，需重启/加入 PATH 才能被 GUI 进程继承）；Ghidra/JADX/TShark/Syft 等未安装。截图 `gui-tool-probe.png`。
- **发现并修复的真实缺陷（v1.1.1）**：状态卡首次挂载 TDZ 崩溃（`postAction` 在 `load` 初始化前求值依赖）；external 适配器目录缺 manifest 导致模型在 health 中看到诊断。两者已修复并发布 v1.1.1；178/178 测试、registry 41/8/0。
- **仍无法验证**：Ghidra/JADX/TShark/Syft 适配器（未实现）、macOS/Linux 桌面（无对应主机）、Windows 卸载复测（未在用户真实安装上执行，避免破坏环境）；v1.1.1 需完全重启 Desktop 才会加载。
