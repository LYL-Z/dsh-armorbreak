# v1.0.0 — Initial delivery

**Release date:** 2026-10-20
**Target runtime:** DeepSeek Harness Desktop 0.2.1-rc.2 (Cordis 4.0.x, Node 24)

## Highlights

- Cordis Bundle `dsh-armorbreak` with an `armorbreak` Host row and a
  `preset-armorbreak` agent-preset declaration; no shipped row is overridden.
- 「破甲模式」persona: authorization boundaries, evidence discipline,
  prompt-injection resistance, explicit working method.
- 39 offline capabilities across 8 domains: binary (5), forensics (6),
  android (5), network (7), web (4), sast (5), ctf (5), live (2).
- L0/L1/L2/L3 policy engine enforced in code: scope authorizations, platform
  approval bridge, path/symlink containment, network allowlists + rate limits,
  hard L3 denial.
- Task state machine (14 states), 9 workflow templates, evidence hash chain,
  audit hash chain, Markdown/HTML/JSON/SARIF/PDF reports.
- 8 model-facing tools, 7 bundled skills, browser status card at
  `conversation.composer.dock` reading the read-only `/armorbreak/state` route.
- 128 automated tests; core module line coverage ≥ 80%.

## Verification recorded at delivery

- `plugin_manager install_bundle` → `application: applied`, no warnings.
- Live Loader shows both rows; `GET /armorbreak/state` → 200,
  39 capabilities / 8 domains / 0 diagnostics.
- Real PE workflow (`BinaryStaticAnalysis` on `notepad.exe`) completed 7/7 steps.

## Known limitations (as published)

See `docs/known-issues.md`. Most notable: external-tool outputs were detection +
guidance only; L1/L2 success paths could not be exercised on the delivery host
(no Docker daemon, no authorized lab target); PDF export requires LibreOffice.
