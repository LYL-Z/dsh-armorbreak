# v1.0.1 — Tool output & workspace fixes

**Release date:** 2026-10-20
**Type:** PATCH (bug fixes found in a real installed session)

## Fixed

1. **`armorbreak_health` failed with `value is not lossless JSON`.**
   `runtime.stateSummary()` returned `tools: registry.list()`, whose capability
   objects carry `run` / `networkTarget` functions. The Harness audit channel only
   accepts lossless JSON.
   - Removed the redundant `tools` field from the state snapshot.
   - Added `toLosslessJson()` in `tools.js`: functions, `undefined`, BigInt,
     cycles and non-finite numbers can no longer escape any tool output.
2. **Default workspace fell back to the host process cwd** (a profile directory in
   Desktop). Tools now resolve the calling session's working directory through
   `ctx.get('workingDirectory').ensure(agent)`; an explicit `workspace` argument
   still wins, and the process workspace remains the fallback.

## Tests

- Added `tests/tools-lossless.test.mjs` (4 cases): recursive lossless-JSON
  validation for every tool output, no raw capability objects in health, default
  workspace = session directory, explicit workspace override.
- Full suite: **132 / 132 passing**.

## Verification

- Fresh test profile booted the fixed runtime; `GET /armorbreak/state` returned
  `version=1.0.1`, 39 capabilities, no `tools` field.
