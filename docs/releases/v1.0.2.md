# v1.0.2 — Directory workflows, hash-chain concurrency, hardening

**Release date:** 2026-10-20
**Type:** PATCH (structural defects reported from real routed executions)

## Fixed

1. **Directory-target workflows were structurally unusable.**
   `WebCodeSecurityReview` / `DependencyAudit` declare `targetKind:'directory'`,
   but `sast.scan/secrets/deps/sbom` did not declare `targetKind`, so planning
   defaulted to `file` and every step failed with `TARGET_NOT_FILE`. Even the
   error message recommended the very capability that was failing.
   - sast capabilities now declare `targetKind:'directory'`.
   - Planning validates each step's declared target kind against the task target
     kind and fails with `TARGET_KIND_MISMATCH` before any step executes, listing
     the registered directory-capable capabilities.
   - `TARGET_NOT_FILE` now lists real directory capabilities and suggests directory
     workflows.
   - `env.readFile` returns a **Buffer** as documented (it returned
     `{buffer,truncated,size}`, which broke SAST file reads).
   - New integration test runs the workflow on a real multi-file project:
     4/4 steps DONE, findings span multiple files, report generated.
2. **Concurrent audit/evidence appends could fork the hash chain** (read-tail →
   append had no serialization). Added a per-file in-process mutex; `AuditLog.append`,
   `EvidenceStore.addEvidence/addFinding/verifyFinding` and `TaskStore.save` are
   serialized. New concurrency tests assert one continuous chain under `Promise.all`.
3. **`scope.js` / `tasks.js` were not valid UTF-8** (an em-dash/arrow was corrupted
   by a lossy text round-trip). Repaired; added a repository-wide UTF-8 validation
   test.
4. **Directory `readFile` was not realpath-checked**: a junction/symlink planted
   inside the analyzed root could redirect reads outside it. Both the root and the
   resolved file are now checked; `listFiles` start paths are checked too. Windows
   junction escape test added.
5. **Port-scoped authorizations/approvals matched portless targets.** Now a target
   with an unknown port never matches a port-scoped pattern; end-to-end tests added.
6. **YAML subset parser hardening**: flow collections had unbounded recursion, and
   `__proto__` / `constructor` / `prototype` keys could mutate the parsed object's
   prototype. Added depth limits (64 flow / 128 indented) and explicit dangerous-key
   rejection, with tests.
7. **Status card displayed misleading data**: isolation provider shown even when
   unavailable; "0 tasks" because the default workspace was the process cwd. The
   snapshot now uses the **most recently used workspace**, labels it as such, and
   shows "unavailable" when no isolation provider is usable.

activates a newly installed bundle.
