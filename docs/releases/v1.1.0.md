# v1.1.0 — Research Workbench (Stage A–D)

**Release date:** 2026-10-20
**Baseline:** v1.0.3 → v1.0.4 (Stage A) → Stage B (external tools) → Stage C/D (workbench)

## Delivered

- **Stage A (v1.0.4)**: strict preset (no generic fs/shell/web bypass), policy-gated `armorbreak_files`, request→platform-approval→activate authorizations, bounded/pinned HTTP probes, digest-pinned non-root L1 containers, UNC/device path rejection, loopback-only state routes.
- **Stage B**: real Semgrep 1.181.0 / Trivy 0.76.0 adapters with normalized findings/evidence (Gate B reproduced, 6 + 67 findings; 150-record evidence chain verified).
- **L1 real path**: `scripts/verify-l1.mjs` verified exit=0, uid=65534, read-only sample mount, no eth network; CI `live-docker` job passes.
- **Stage C**: DAG workflow engine (dependsOn, failure policies, retry, timeout, bounded concurrency), background task queue (start/status/wait/cancel/recover/resume), restart recovery (INTERRUPTED/RECOVERABLE, stale RUNNING→PENDING), tool actions run_async/resume/retry.
- **Stage D/D2**: loopback read-only workbench routes + write actions for L0 tasks (create/cancel/retry/resume), evidence center (bounded, filters, hash-chain), report preview (bounded text), external-tool probe; browser status card with overview/tasks/tools tabs.
- **Verification**: 177+ automated tests, Windows/Ubuntu CI, Docker L1 job, mock-model tool-flow E2E.

## Not verified / known limits

- Real DeepSeek model desktop GUI E2E (no desktop model credentials in this environment).
- Browser visual rendering/interactions were not verified by an attached browser; only syntax, route and logic tests.
- Workbench write actions are L0-only by design (browser has no approval channel); L1/L2 remain conversation tools.
- Session workspace binding applies after the session's first tool call; otherwise MRU fallback.
- Ghidra/JADX/TShark/Syft adapters, full EvidenceExplorer/ReportPreview productization, macOS/Linux desktop, and Windows installer re-test are not covered.
