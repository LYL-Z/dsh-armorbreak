# v1.1.1 ‚Äî Hotfix (client card + analyzer diagnostics)

**Release date:** 2026-10-20
**Baseline:** v1.1.0

Found by **real desktop GUI + real model E2E verification**:

1. **Status card crashed on mount (TDZ)** ‚Äî the D2 browser workbench declared
   `postAction` with `[load]` before `load` was initialized, throwing a
   temporal-dead-zone error during render. Fixed by removing the render-time
   dependency evaluation (the callback still resolves `load` at event time).
2. **Analyzer diagnostics reported `external` analyzer load failure** ‚Äî the
   external adapter module lived in `lib/analyzers/external/` without a
   `manifest.js`, so the domain loader reported a diagnostic and the model
   observed it via `armorbreak_health`. Moved to
   `lib/analyzers/sast/external-adapters.js` (registered by the sast manifest),
   so the registry is diagnostic-clean again.
