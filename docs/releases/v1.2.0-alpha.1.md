# v1.2.0-alpha.1 — Advanced Research (in progress)

**Status:** alpha, not a complete v1.2.0 release.
**Baseline:** v1.1.1

## Delivered in this increment

- `armorbreak_environment` (10th tool): detect Docker / Podman / WSL2, distinguish
  `Unavailable` / `Installed` / `DaemonReady` / `IsolationVerified`, report the
  recommended provider and installation links. Detection never implies isolation;
  WSL2 is not treated as a security sandbox.
- `binary.behavior` (42nd capability): aggregate suspicious import categories,
  predefined high-risk combinations (injection+execution, credential+network,
  collection+network…), a 0–100 heuristic score and evidence anchors. Everything
  is hypothesis-level; the sample is never executed.
- Workspace persistence: the most recently used workspace is saved under the
  state root so a restarted process no longer falls back to the profile directory;
  binding text now says "call an ArmorBreak tool to bind this session".

## Verification

- `node --test`: 182/182.
- Registry: 42 capabilities / 8 domains / 0 diagnostics.
- Isolation manager tests cover absent CLI, CLI without daemon, daemon-ready,
  injected self-test success/failure, WSL2 non-sandbox semantics and install links.
