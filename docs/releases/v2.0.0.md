# v2.0.0 — ArmorBreak 破甲模式 V2

**Release date:** 2026-10-21
**Type:** security-research agent preset / Cordis bundle for DeepSeek Harness

## What changed

- **Policy gateway:** L0 read-only, L1 isolated execution, L2 active testing, L3 permanent deny. Unknown actions deny by default. Model output can never authorize an install or approval.
- **46 capabilities / 9 workflows**, preserved v1.2 API and profile data migration.
- **Connectivity:** KEV / EPSS / OSV live ingestion, versioned Ed25519-signed indexes, license/404/rate-limit states.
- **Supply chain:** signed bundle lock, SBOM, license gate, transactional installer with plan → stage → verify → approve → activate → rollback.
- **AISEC:** Garak 0.17.1, PyRIT 1.1.0, JailbreakBench adapters; raw harmful payloads are never exported.
- **Workbench:** overview/tasks/network/evaluations/knowledge/catalog/installations/reports, evidence chain and Markdown/HTML/JSON/SARIF reports.
- **Desktop:** real Windows DSH Desktop GUI E2E with the `armorbreak` preset and live model tool calls.

## Known limitations

- Isolation provider is **Unavailable** in the verified environment; L1/L2 were not executed.
- External tools installed: **5/25**.
- PDF export unavailable without LibreOffice; Markdown/HTML/JSON/SARIF are supported.
- No third-party live model endpoint was used for AISEC; Garak used the offline `test` generator and PyRIT used an official local `PromptTarget`.
- Linux/macOS desktop behavior was not verified in this release.

## Upgrade

V1 profile data is preserved; the V2 installer performs a migration preview and requires operator approval before activation. Use `docs/v2/release/upgrade-guide.md` and keep a profile backup for rollback.
