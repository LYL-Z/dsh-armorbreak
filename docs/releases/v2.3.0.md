# ArmorBreak V2.3.0 Stable — release notes draft

This is the prepared public release-notes draft for V2.3.0. It is not a release announcement until a public, non-prerelease GitHub Release exists and its assets have been downloaded and verified. The owner has authorized the release process and selected the transparently disclosed `OWNER_APPROVED_SELF_REVIEW` policy; no independent human audit is claimed.

## Candidate implementation

The candidate adds bounded artifact identification/inventory, JavaScript/TypeScript symbol records, PE/ELF/Mach-O program IR with optional Ghidra output, offline security evidence correlation, finite comparison of caller-supplied behavior results, capability support metadata, and a fixed MCP workflow discovery/start route. Ghidra and the native Program IR route require L1 approval because Ghidra is an external native parser over untrusted binaries; no host sandbox is provided. The HTTP MCP transport is limited to one configured principal and one fixed workspace per process.

## Not included or not verified

- Full multi-language semantic analysis, four-language S3, inter-file taint, or universal behavior reconstruction.
- Bytecode/package coverage beyond evidence already in the project; APK/DEX refresh and other bytecode families remain unverified or deferred.
- Independent human vulnerability and license review (not performed; release uses owner-approved developer AI self-review).
- Multi-principal HTTP service and cross-Windows-account isolation; only single-principal-per-process mode is supported.
- OS-integrated updater (not part of V2.3.0 Stable scope); use documented Portable/manual or npm install paths.
- Universal decompilation, arbitrary-language semantic analysis, inter-file dataflow, or general behavior reconstruction.
- macOS host/runtime unless independently listed as verified in the final matrix.

This product is not a universal reverse-engineering or program-cracking system. Source symbol analysis is limited to bounded JavaScript/TypeScript local structure; behavior comparison is limited to supplied finite cases. The Stable release must disclose exact CI and asset hashes and state that security/license review is an implementing-agent self-review, not an independent audit.
