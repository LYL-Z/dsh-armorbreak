# ArmorBreak 2.3.1 Stable

**Status: RELEASED.** Public GitHub Release: <https://github.com/LYL-Z/dsh-armorbreak/releases/tag/v2.3.1> (published 2026-11-08; not a draft or prerelease).

The protected annotated tag `v2.3.1` points to exact `main` commit `cfb984b7178bb8b1dca9728325fdbe599b5430a3`. The failed protected `v2.3.0` tag and its original Gate failures remain unchanged.

## Why 2.3.1

The `v2.3.0` Tag Gate failed twice in the Windows deployment/rollback job. Its retained logs stop at a combined task/report assertion and do not identify which read failed. V2.3.1 added separately redacted diagnostics and moved the real V2.2-to-candidate deployment and rollback check to PR and exact-main validation, before creation of the immutable release tag.
