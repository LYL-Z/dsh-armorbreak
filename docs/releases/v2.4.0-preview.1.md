# ArmorBreak 2.4.0-preview.1 — 开发预览

这是供开发者和测试用户体验的 **Preview**，不是 v2.4 Stable，也不表示两个 Purge 仓库已经全量融合。v2.3.1 Stable 的 Tag、Release 和原始资产保持不变。

## 可以实际使用

- Windows：核对 `SHA256SUMS.txt` 后完整解压 `ArmorBreak-Windows-Preview.zip`，打开 `Start ArmorBreak.cmd`。需要已安装 Node.js 22+；包内包含应用及锁定的运行依赖，免去手动执行 npm 命令。
- Linux/Windows 技术用户：安装本页的 npm TGZ，使用 CLI、MCP 或 `armorbreak start --workspace /absolute/project`。
- 工作台：运行安全示例；检查项目代码、依赖和文件；执行综合项目审查、七步离线抓包分析及六步文件取证；查看实际步骤结果，下载合并报告。
- 受信宿主的实验接口：在隔离合成目录中审批配置应用与原始字节恢复，以及插件包安装、升级、禁用、恢复文件选择、卸载与回滚。插件代码不会被执行。

## 验证与来源

资产附带准确提交、SHA-256、SBOM、许可证文本及 GitHub 托管构建的签发证明。发行流程要求同一 main 提交的 Windows/Linux、Node 22/24、L0、真实 Docker L1 和实际安装检查成功；跳过项不被记为成功。它还核对新建草稿的实际下载字节后才公开为 prerelease。

可用 GitHub CLI 检查主资产：`gh attestation verify <文件> --repo LYL-Z/dsh-armorbreak --signer-workflow LYL-Z/dsh-armorbreak/.github/workflows/v24-preview-release.yml --source-ref refs/heads/main --source-digest <preview-build.json 中的 commit> --deny-self-hosted-runners`。
