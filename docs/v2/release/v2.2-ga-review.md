## 3. 签名与信任边界

`portable-artifact.json` 的 `signed:true` 是 **GitHub OIDC + Sigstore 构建来源证明**，不是传统代码签名证书或项目私钥签名。它证明 artifact 由本仓库 GitHub Actions 构建并对应源码 commit/digest，不证明代码正确性、不替代独立审查、不构成发布授权。

## 4. 安装、升级与回滚
