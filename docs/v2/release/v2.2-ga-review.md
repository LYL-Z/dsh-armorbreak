## 3. 签名与信任边界

`portable-artifact.json` 的 GitHub OIDC + Sigstore attestation 是构建来源证明，不是生产 artifact signature。Full GA 分别验证 Sigstore 来源证明和由 `production-signer` 角色密钥签署的确切制品摘要；两者都不替代独立审查或 Provider/host 外部证据。
