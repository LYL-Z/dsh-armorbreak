1. **Claude Code 模型未登录**：`claude mcp list` 已显示 ArmorBreak `Connected`（`claude-code 2.1.299`，7 工具），但 `claude -p` 返回 `Not logged in · Please run /login`，代理尝试为 401；环境无 `ANTHROPIC_*` / `CLAUDE_CODE_OAUTH_TOKEN`。不得代替用户登录或窃取凭据。
2. **宿主缺口**：ZCode 仅有 MCP 握手、无模型 L0；Antigravity/Pi 未安装。Cursor/TRAE/WorkBuddy 已完成真实模型 L0。
3. **无生产签名密钥/发布凭据**：仓库只有 Ed25519 原语和测试密钥；生产私钥不应提交到仓库。
4. **无真实付费 Provider 凭据**：OpenAI/Anthropic/Gemini 付费端点未调用；本地 Ollama 已通过 chat/SSE/tool loop。
5. **C 盘空间已恢复到约 10 GB**，Docker/WSL 已迁到 D 盘；不再是当前阻断。
