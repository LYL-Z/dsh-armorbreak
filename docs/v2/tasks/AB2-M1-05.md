# AB2-M1-05 RESOURCE_READ 只读连接器

## 已实现

- `ResourceFetcher`：固定 connector registry（CISA KEV / FIRST EPSS / OSV），**默认拒绝网络**；只有 `allowNetwork:true` 才可请求。
- 只能 GET 注册表中的 https URL；不接受任意用户 URL；不跟随重定向；超时、响应体上限、来源/许可/ETag/Last-Modified/内容 SHA-256 均记录。
- 返回值明确标记 `permission: RESOURCE_READ`、`activeTesting:false`，与 L2 主动测试分离。
- PolicyGateway `resource.read` 只允许 connector allowlist，且不会调用 `scope.checkNetwork`。
- 测试：默认关闭、未知 connector、重定向、HTTP 错误、size limit、非 JSON 资源均有负向用例。

## 未完成（REVIEW）

- 尚未接入 Host 同步调度、缓存/staging 与 UI 诊断；没有执行真实公网资源同步（按任务书，联网需授权，不能默认打开）。
- 没有把 ResourceFetcher 暴露为模型工具；当前先作为受控 Host 模块，避免模型直接触发外网。

## 验收结论

权限边界与 URL/大小/重定向防护通过本地测试；真实数据源同步与 UI 入口未完成，因此不标 DONE。
