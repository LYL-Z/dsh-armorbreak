# AB2-M1-05 RESOURCE_READ（DONE）

## 实现

- `ResourceFetcher`：默认禁止外网；只有固定 connector registry（https）可请求，不接受模型/用户任意 URL；不跟随重定向；超时、大小、许可、ETag、SHA-256 全部记录。
- `ResourceSyncManager`：单源同步 → staging → LayeredCache cloud 激活；源失败由 ConnectorHealth 隔离，网络状态转 OFFLINE，但不阻断其他源。
- Runtime 初始化 ResourceFetcher（`ARMORBREAK_RESOURCE_READ=1` 才开）、NetworkState、ConnectorHealth、ResourceSync。
- PolicyGateway `resource.read` 只允许 connector allowlist，返回 `activeTesting:false`，不调用 L2 网络授权。
- 测试：
  - fetcher 默认关闭、未知 connector、重定向、HTTP 错误、大小上限、非 JSON
  - sync 单源成功/单源失败隔离、RESOURCE_READ 关闭拒绝

## 残余

- 未在真实公网数据源执行同步；默认关闭是刻意的运行策略，不表示外部源已验证。
- 同步调度/UI 入口未完成；M2-05 的数据源适配会复用本模块。
