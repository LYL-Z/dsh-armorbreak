# AB2-M1-06 Workbench loopback API 安全自检

## 已实现/验证

- 所有 read-only 路由继续要求 loopback peer、GET/HEAD、拒绝 `workspace` 参数。
- 新增同源 Origin fence：请求带 Origin 时必须是 `127.0.0.1/localhost/[::1]` 且与 Host 完全一致；`Origin: null` 与外部源均 403。无 Origin 的 Electron/CLI 路径保持兼容。
- POST `/armorbreak/actions` 同时要求 loopback + same-origin + `x-armorbreak-ui: 1` + `application/json` + 64 KiB body 限制。
- session 只解析本次进程记录过的工具工作区；未知/非法回退 MRU，不枚举目录。
- 测试：`tests/ui-api.test.mjs` 10/10 通过；覆盖非 loopback、POST 方法拒绝、workspace 枚举、恶意 Origin、null Origin、同源通过、action header 拒绝、session 绑定与回退。

## 残余

- 未实现用户级身份认证；按架构这是本机桌面 loopback 信任模型，依赖 OS 用户隔离。若未来把 Web UI 绑定到非 loopback 地址，必须重新做认证设计，不能沿用本结论。
