# AB2-M1-08 v1→v2 迁移/回滚（DONE）

## 实现

- `planMigration`：只读扫描 `.armorbreak/tasks/*/task.json`，输出 before SHA-256、needsMigration、invalid。
- `applyMigration`：先为所有目标写备份，再写 `status=prepared` manifest，之后才逐项 temp+rename 替换；成功后 manifest 改 `completed`。
- `rollbackMigration`：校验备份 hash 后用相同原子写恢复原始字节。
- `recoverInterruptedMigrations`：扫描未完成 manifest，自动恢复全部备份并标记 `rolled-back`。
- CLI：`node scripts/v2/migrate.mjs --workspace <dir> [--apply|--rollback <manifest>]`。

## 故障注入验证

- **EACCES**：替换第 2 个任务前注入权限错误；恢复后两个原始 task.json 逐字节不变。
- **ENOSPC**：注入磁盘满错误；恢复后原始字节不变。
- **真实 SIGKILL**：子进程调用迁移并在替换前 `process.kill(SIGKILL)`；父进程从 prepared manifest 恢复两个任务，原始字节不变。
- 保留只读 plan、apply/rollback 字节一致性、非法数据拒绝测试。

## 残余

- 未在真实用户 `.armorbreak` 数据上执行；只在临时工作区演练。
- 只迁移 task.json 元数据，未迁移 evidence/findings 的 schemaVersion。
- 未做真实磁盘写满（以注入 ENOSPC 模拟）与断电测试。
