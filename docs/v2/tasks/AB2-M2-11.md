# AB2-M2-11 Transactional Installer（DONE）

## 实现

- `plan`：调用 License/SBOM gate；拒绝未知许可/危险脚本/缺 commit-digest；生成不可变 `planHash`，`executePackageCode=false`。
- `stage`：先验证 artifact hash，再复制到独立 staging（不执行任何包脚本）。
- `verify`：再次验证 staged artifact hash。
- `approve`：必须提供 Host ApprovalAuthority token，绑定 planId/planHash/operator；无 token 拒绝。
- `activate`：仅 APPROVED 可执行；复制 artifact、记录不可变 manifest、原子切换 active pointer。
- `rollback`：恢复 previous active pointer 并清理 installed/staging；`fail` 清理 staging，无半安装。
- 测试 3/3：未知许可拒绝、未批准不得激活、token 绑定、失败清理、rollback。
