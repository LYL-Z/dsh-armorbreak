# AB2-M3-02 Python worker 服务协议（DONE）

## 实现

- Python stdlib worker：JSONL 协议 `armorbreak.aisec-worker/v1`；支持 ping/env/evaluate/sleep/crash/shutdown。
- 依赖锁定 `requirements.lock`：CPython >=3.10，无第三方依赖；本机实测 3.11.9。
- Supervisor 使用显式环境 allowlist；Host 秘密不继承（测试验证 secret absent）。
- 超时：kill worker、拒绝 pending、下一次请求自动重启。
- 崩溃：`crash` 退出码 7，pending 收到 WORKER_EXITED，下一次 ping 正常。
- 取消：`cancelAll` 拒绝 pending 并确保无运行 child。
- 测试 4/4。

## 残余

- Worker 目前是 mock/stdlib 能力；Garak/PyRIT/Inspect 适配在 M3-03–05。
- 未做多进程池/并发调度；当前串行请求足够 M3 基准。
