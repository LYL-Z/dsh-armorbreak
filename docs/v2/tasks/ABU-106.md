# ABU-106 bounded engine API / cancellation

- 所有公共 Engine 方法经 `bounded` 包装：create/get/list/cancel、evidence、report、envelope、analyze、capabilities、health、workflows、approval。
- 支持 AbortSignal 预取消与 requestTimeoutMs。
- 支持 invocation `deadline`（ISO timestamp）；过期立即 TIMEOUT，非法格式 INVALID_REQUEST。
- analyze 将取消 signal 传给 Core runner。
- 保留 requestId 幂等、任务取消、envelope 事件写入。
- 输入/输出边界：title/objective/targetPath、evidence 200、report 256 KiB、task list 20。
- 未实现自动 retry；不属于本任务验收。
