# ABU-107 Event/Evidence Envelope

- Envelope 固定 `traceId/runId/taskId/principalId/origin/targetHash`。
- 敏感 key 递归 redaction；只保存 sanitized payload 的 SHA-256；禁止原始 secret。
- 非法 targetHash / envelope 校验失败即拒绝。
- Engine 已将 envelope 写入现有 TaskStore/EvidenceStore 证据链，`verifyChain()` 通过；abort 后拒绝写入。
