# ABU-203 MCP Streamable HTTP (slice)

- `POST /mcp` JSON-RPC；`GET /health`。
- 默认只允许 loopback（127.0.0.1/::1/localhost）；拒绝 0.0.0.0 绑定。
- 可选 Bearer token；配置后无 token 返回 401。
- content-type 必须 application/json，body 上限 1 MiB。
- 生成 `mcp-session-id` 响应头；Origin 必须是 loopback；Host 必须是 loopback。
- 支持 `Accept: text/event-stream` 的 SSE `event: message` 响应。
- 支持显式 `tls:{key,cert}` 启动 HTTPS；测试使用自签证书并 `rejectUnauthorized:false`。
- 测试覆盖 initialize、tools/list、capabilities、401、非 loopback 绑定、恶意 Origin、恶意 Host、SSE、HTTPS。
- 已实现可恢复 session：`stateRoot/mcp-http-sessions.json` 持久化 session，重启后可用原 `mcp-session-id` 继续 tools/list；过期返回 404。
- 已实现多主体 token 绑定：`tokens` 将 Bearer 映射到不同 principal/workspace，跨身份复用 session 返回 403；默认单 token/无 token 模式保持兼容。
