# ABU-209 agent install CLI

- `armorbreak agent install --target claude|codex|hermes --config <path> --scope user|project`
- 默认 dry-run，输出 before/after，不写盘；`--apply` 才写。
- 支持 `--force` 升级，冲突默认拒绝。
- JSON/TOML/YAML 三种 host 配置分别走事务 installer。
- `--uninstall` / `--disable` 先保留 `.armorbreak.bak`，只移除 armorbreak，保留其他 server。
- 测试覆盖 dry-run 无写入、apply、backup、uninstall、TOML、YAML、冲突拒绝。
- 不猜测宿主默认路径；`--config` 必须显式提供。
