# ABU-210 MCP Streamable HTTP (slice)

- `POST /mcp` JSON-RPC；`GET /health`。
- 默认只允许 loopback（127.0.0.1/::1/localhost）；拒绝 0.0.0.0 绑定。
- 可选 Bearer token；配置后无 token 返回 401。
- content-type 必须 application/json，body 上限 1 MiB。
- 测试覆盖 initialize、tools/list、capabilities、401 与非 loopback 拒绝。
- 尚未实现 SSE/streaming、session/resume、TLS 和远程身份；PARTIAL。
