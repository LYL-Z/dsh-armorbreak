# ABU-316 unified tool-loop / retry / budget

- `runToolLoop` 支持：
  - maxTurns 1..32
  - deadline
  - budgetTokens
  - 429/5xx/retryable 指数退避重试（可注入 sleep）
  - tool call ID 保留
  - tool 执行错误转为 isError 消息
- 测试覆盖 tool ID、maxTurns、budget、deadline、429 retry、tool error。
- 真实本地 Ollama 3 轮工具循环执行 `armorbreak_health` 并返回 `DONE`；usage 已归一化，预算可生效。
- 仍缺：stream 事件累积、tool id 错位负例、replay/重复消息检测、真实付费 provider 端点；PARTIAL。
