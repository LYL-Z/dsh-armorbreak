# ABU-316 unified tool-loop / retry / budget

- `runToolLoop` 支持：
  - maxTurns 1..32
  - deadline
  - budgetTokens
  - 429/5xx/retryable 指数退避重试（可注入 sleep）
  - tool call ID 保留
  - tool 执行错误转为 isError 消息
- 测试覆盖 tool ID、maxTurns、budget、deadline、429 retry、tool error、duplicate ID、replay、stream 事件累积。
- 真实本地 Ollama 3 轮工具循环执行 `armorbreak_health` 并返回 `DONE`；usage 已归一化，预算可生效。
- 真实流式 tool loop：2 轮、117 个 SSE 事件、727 tokens、最终 `STREAM_DONE`，tool 执行 1 次。
- 已实现 stream 分支、跨轮 tool-call ID 去重和 replay 拒绝；付费 provider 端点仍由 ABU-311/313/314 承担。
