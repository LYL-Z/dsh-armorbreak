# ABU-402 transactional host config installer (JSON slice)

- 支持 Claude 项目 `.mcp.json` / Cursor JSON 形态的 MCP server 合并。
- dry-run plan 不写盘；apply 前保留 byte-for-byte backup。
- rollback 恢复原始文件；uninstall 只删除 armorbreak，保留其他 server。
- 冲突默认拒绝，`force` 才替换；禁止明文 apiKey/token/secret 字段。
- 非法 JSON 在写盘前失败。
- Codex 风格 TOML 使用 managed markers：dry-run、force 升级、uninstall、rollback。
- 未托管同名 TOML table 默认拒绝，避免覆盖用户配置。
- Hermes YAML：managed 缩进块，支持添加/force 升级/uninstall/rollback；未托管冲突拒绝。
- 可复现构建/来源 pin：`build-release.mjs` 固定排序、mtime/uid/gid，manifest 记录 commit/hash；安装器仍通过 JSON/TOML/YAML 测试。
- v2.2 candidate 在真实宿主上的全新安装尚未执行：`hostInstall: BLOCKED_EXTERNAL`。
