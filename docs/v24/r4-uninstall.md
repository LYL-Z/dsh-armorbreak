# Isolated plugin deselection and recovery

Feature reference: PC-COMMUNITY-OP-84bbfdf0 (PARTIAL_IMPLEMENTATION_TESTED only). The fixed upstream bin/community.js delegates uninstall to bin/dsh-purge.js, which calls lib/uninstall.js. Upstream also restores host patches, removes profile dependencies/shims/rules and deletes installed trees. Those real-host and destructive behaviors are not imported or executed here.

Trusted host entry: `planIsolatedPluginInstall(runtime, { operation: 'uninstall', current, reviewer, operator, sessionId })` from `dsh-armorbreak/isolated-plugin-store`. Call `store.apply(oneUseApprovalProvider)` only after host review. This creates a fresh bounded transaction, retains sealed private historical files, and commits an empty NOT_INSTALLED selector. Ordinary reads and copies then fail. Independently approved `store.rollback(provider)` restores the exact previous selector and byte content; disabled/revoked state still restricts public exports. Unknown partial bytes or damaged evidence refuse automatic restoration. Existing directory destinations and candidate payloads are rejected for uninstall.

This is transaction-local quarantine deselection, not removal of a real DSH plugin. Old independently retained transaction roots are immutable history and are not a shared live host installation: this operation does not retroactively revoke their separate handles. Payload snapshots are retained for recovery, not securely erased or garbage-collected. No global installed-package registry, real profile cleanup, patch restoration, runtime unloading, restart compatibility, OS ACL recovery, multi-user or power-loss acceptance is established. Consequently no complete upstream equivalence or INTEGRATED_VERIFIED status is claimed.

Tests exercise approved/denied/replayed apply, separately denied/approved/replayed rollback, reopen, disabled/key-revoked/authority-revoked histories, wrong arguments, drift and post-selector interruption. Actual installed TGZ acceptance additionally invokes uninstall and raw-byte restore. The implementation is original ArmorBreak code, with no upstream executable copied.
